# PaceLink

Karting telemetry analysis for AiM MyChron 6, by VILIM Motorsport.

This repository only holds the Windows installers of PaceLink and the update information the
installed app reads. Download the newest version from
[Releases](https://github.com/CaptainSchumi95/PaceLink-releases/releases/latest).

**Install:** run `PaceLink_<version>_x64-setup.exe` (installs for the current user, no
administrator needed). Windows SmartScreen may warn about an unknown publisher: choose
*More info → Run anyway*.

**Updates:** PaceLink shows an *Update* button when a new version is available.
